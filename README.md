# PCP 彈道計算（單頁離線版）

仿 Strelok Pro 風格的 PCP（預充氣式氣槍）彈道計算 App，**單一 HTML 檔、零外部依賴、可完全離線使用**。
用手機或電腦瀏覽器直接開啟 `index.html` 即可。

## 功能

- **彈道學頁**：輸入距離、俯仰角、風速、風向（時鐘制）、天氣（溫度／氣壓 QNH 或測站／濕度／海拔），即時顯示 MRAD／MOA／公分／響數修正值與剩餘速度、動能、飛行時間；附靶場快速表與彈道側視圖
- **分劃板頁**：白色鏡視圖十字準心（Strelok 風格），紅字標各距離持握點、黃色靶環標目前距離（含風偏持握）、粉紅曲線為 2／5／10 m/s 全值側風持握線（L-R 鈕切換風向側）
- **裝備頁**：槍枝設定檔管理（LocalStorage 自動儲存、JSON 匯出／匯入）、彈藥與瞄準鏡參數（FFP／SFP、每格響數值、MIL／MOA 切換）

## 物理引擎

- 四階龍格-庫塔（RK4）三維點質量積分，Δt = 1 ms，絕非真空拋物線
- GA（蘑菇頭鉛彈）／ G1（Slug）雙阻力係數表，馬赫數線性插值
- 大氣模組：Magnus 飽和水汽壓、虛溫音速、海拔氣壓修正、實際空氣密度
- 二分法歸零求解（含鏡高）、射擊仰俯角重力分量修正、三維風向量
- 已與 Strelok Pro 實測對照：Kral Puncher .22 / Crosman 14.3gr（G1 BC 0.0190、850 fps、歸零 40 m）於 50 m 計算值 0.81 MRAD，與 Strelok 相同

## 使用方式

1. 下載 `index.html`
2. 用瀏覽器開啟（手機可加入主畫面當 App 用）
3. 到「裝備」頁選擇或建立你的槍枝設定檔，回「彈道學」頁輸入距離即得修正值

> 本工具僅供合法運動射擊與狩獵用途之彈道估算參考。
